Brawl Stars Reinforcement Learning Active

Jul. 2026 – Present Personal project Python · PyTorch · RL

I'm building a reinforcement learning agent that plays the mobile game Brawl Stars at a competitive level, paired with a computer-vision pipeline that reads game state straight from raw frames.

  • Wrote a custom vectorized simulator that mirrors Brawl Stars' mechanics so I can run huge batches of matches in parallel instead of being bottlenecked by the real game.
  • Training the policy with Proximal Policy Optimization (PPO) — roughly 300 million simulated matches so far.
  • Documenting each stage of development in a YouTube series, which has passed 500,000 views.
